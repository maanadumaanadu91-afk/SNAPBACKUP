SnapBackup API Reference

          
Base URL: https://api.snapbackup.dev/v1

        

        
      


      

        
        

          

            POST
            /v1/save
          

          
Creates a new encrypted JSON snapshot for your application.

          

            

          

        


        
        

          

            GET
            /v1/restore/:snapshot_id
          

          
Fetches a saved snapshot payload (or use latest as the ID) to hydrate your app state.

        


        
        

          
Payload Parameters

          

            

              
                

                  Field
                  Type
                  Description
                

              
              
                

                  access_key
                  string (req)
                  Your public write-only backup key from Step 1.
                

                

                  app_name
                  string
                  Logical namespace for grouping app snapshots.
                

                

                  data
                  object (req)
                  Arbitrary JSON state object (up to 5 MB per snapshot).
                

                

                  retention_days
                  number
                  Optional retention window (default: 30, max: 1095).
